# Prompts

This project was built in a single working session with **Claude** (Anthropic), used as a pair programmer. This file lists the prompts I gave it, in order, and what each one produced.

The original prompts were short and written in Spanish. They are translated and edited here for clarity; the intent and the sequence are unchanged. Routine exchanges, such as pasting a terminal error to resolve a local setup issue, are summarised rather than listed one by one.

## How I worked

- **Plan first, then code.** Before each block of work I asked for a structure or a proposal, and only then for the implementation.
- **One layer at a time.** Backend core, then the HTTP layer, then expressions, then the frontend, then deployment. I did not move on until the current layer ran on my machine.
- **I verified each step myself.** I ran the Go tests, sent every request in `backend/api.http`, ran the frontend tests and the dev server, and built and ran the Docker image.
- **I set the direction.** The scope, the decision to evaluate full expressions, and the visual direction were my calls. When the assistant moved faster than I had asked, I stopped it and went back to agreeing the structure first.
- **I own the repository.** I created it, placed every file and wrote every commit.
